# 老子 · 著作与系统思考

> 调研说明：《道德经》约五千言，81章（王弼本分章）。作者「老子」是否单一人、成书年代均有学术争议（见06）。原文经维基文库王弼本逐条核验。可信度：一手=《道德经》原文；二手=司马迁等记述。

## 反复出现的核心论点（≥3次=真信念）

### 1. 反者道之动：事物向对立面转化（全书总规律）
- 「反者道之动，弱者道之用」（第40章）——一语总纲
- 「祸兮福之所倚，福兮祸之所伏。孰知其极？」（第58章）
- 「曲则全，枉则直，洼则盈，敝则新」（第22章）——四个方向的同一规律
- 「物壮则老，是谓不道，不道早已」（第30、55章两见）——盛极必衰
→ 揭示：任何状态都内含走向反面的种子——这是老子一切策略判断的物理学。

### 2. 无为而无不为：最小干预原则
- 「道常无为而无不为」（第37章）
- 「为学日益，为道日损。损之又损，以至于无为。无为而无不为」（第48章）——做减法的路径图
- 「治大国，若烹小鲜」（第60章）——过度翻动即毁
- 「民之难治，以其上之有为，是以难治」（第75章）——折腾是问题的来源而非解法
→ 揭示：无为不是不作为，是去掉妄为（违背系统自身节律的干预）。

### 3. 守柔处下：以低胜高的位置策略
- 「上善若水。水善利万物而不争，处众人之所恶，故几于道」（第8章）
- 「天下莫柔弱于水，而攻坚强者莫之能胜」（第78章）
- 「圣人后其身而身先；外其身而身存」（第7章）
- 「知其雄，守其雌」「知其白，守其黑」（第28章）——明知强而守弱的主动选择
- 「江海所以能为百谷王者，以其善下之」（第66章）
→ 揭示：低位是汇聚资源的位置，柔弱是时间维度上的强者。

### 4. 有无相生：「无」的功用
- 「凿户牖以为室，当其无，有室之用」（第11章）——房间有用因为空
- 「三十辐共一毂，当其无，有车之用」——同一章三个例子（车、器、室）
- 「有之以为利，无之以为用」（第11章）——有是便利，无是功用
→ 揭示：系统真正的功能空间在「空」处——留白、冗余、不被填满的时间。

### 5. 知足知止：边界的智慧
- 「知足者富」（第33章）
- 「祸莫大于不知足；咎莫大于欲得。故知足之足，常足矣」（第46章）
- 「始制有名，名亦既有，夫亦将知止，知止可以不殆」（第32章）
- 「功遂身退，天之道」（第9章，王弼本无「也」字）
→ 揭示：可持续性的来源是自我设界，不是无限扩张。

### 6. 正言若反：悖论式真理观
- 「大直若屈，大巧若拙，大辩若讷」（第45章）
- 「明道若昧，进道若退，夷道若类」（第41章）
- 「信言不美，美言不信」（第81章，末章）
- 「自见者不明；自是者不彰；自伐者无功」（第24章）
→ 揭示：表层与深层常相反——对一切显赫、雄辩、锋芒的系统性怀疑。

## 核心术语表

| 术语 | 定义要点 |
|------|---------|
| 道 | 不可命名的总规律；「道可道，非常道」（第1章）——可说之道非永恒之道 |
| 无为 | 不妄为；去掉违背系统节律的干预 |
| 柔弱 | 时间维度上的强——「柔弱胜刚强」（36章） |
| 朴 | 未剖原木；未分化、未被名分割的状态（「见素抱朴」19章） |
| 谷/水/婴儿/母 | 核心意象群：虚、低、生、根源性 |
| 三宝 | 「一曰慈，二曰俭，三曰不敢为天下先」（第67章）——唯一的伦理清单 |

## 政治哲学（另一个侧面）
- 「太上，下知有之；其次，亲而誉之；其次，畏之；其次，侮之」（第17章）——最好的治理是感觉不到治理
- 「我无为，而民自化；我好静，而民自正」（第57章）
- 「小国寡民……邻国相望，鸡犬之声相闻，民至老死不相往来」（第80章）——反发展主义的理想国（与第80章以外各章的普遍规律并存，保留张力）
- 「圣人不仁，以百姓为刍狗」（第5章）——天地不情感化运作的冷峻面
