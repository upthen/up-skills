# 孟子 · 著作与系统思考

> 调研说明：《孟子》七篇为孟子与其弟子万章、公孙丑等共同编定，孟子本人深度参与——是先秦子书中作者主体性最强的一部。原文已经维基文库逐条核验。可信度：一手=《孟子》原文；二手=他人记述。

## 反复出现的核心论点（≥3次=真信念）

### 1. 性善论：四端说（人性论证的全书地基）
- 「恻隐之心，仁之端也；羞恶之心，义之端也；辞让之心，礼之端也；是非之心，智之端也」（《公孙丑上》）
- 「人皆有不忍人之心……非由外铄我也，我固有之也」（《告子上》）
- 「人皆可以为尧舜」（《告子下》）——性善论的推论：道德潜能人人平等
- 与告子的辩论（《告子上》全程）：仁内义内 vs 仁内义外——通过论战确立立场
→ 揭示：孟子一切政治主张（仁政）都建立在这个人性论地基上——可能性论证先于方案论证。

### 2. 民本：政治合法性的排序
- 「民为贵，社稷次之，君为轻」（《尽心下》14）
- 「桀纣之失天下也，失其民也；失其民者，失其心也」（《离娄上》）
- 「君之视臣如土芥，则臣视君如寇雠」（《离娄下》）——君臣关系的条件性
- 「闻诛一夫纣矣，未闻弑君也」（《梁惠王下》）——暴君失去君之名，革命合法
→ 揭示：合法性来自民心，不是来自天命血统——先秦最锐利的政治学命题。

### 3. 仁政：经济基础先于道德教化
- 「有恒产者有恒心，无恒产者无恒心」（《梁惠王上》《滕文公上》两见）——产权稳定是道德稳定的前提
- 「明君制民之产，必使仰足以事父母，俯足以畜妻子，乐岁终身饱，凶年免于死亡」（《梁惠王上》）
- 五亩之宅、百亩之田的具体方案（《梁惠王上》）——政策具体到土地与桑麻
→ 揭示：孟子不是空想道德家——他先谈经济保障，再谈礼义教化。

### 4. 义利之辨：价值排序的绝对性
- 「王何必曰利？亦有仁义而已矣」（《梁惠王上》开篇第一句——全书定位）
- 「生亦我所欲也，义亦我所欲也；二者不可得兼，舍生而取义者也」（《告子上》）
- 「非其义也，非其道也，禄之以天下，弗顾也」（《万章上》）——给天下也不换
→ 揭示：义不是与利平衡的一极，而是裁决利的天平。

### 5. 养气论：人格的能量学
- 「我知言，我善养吾浩然之气」「其为气也，至大至刚，以直养而无害，则塞于天地之间」（《公孙丑上》2）
- 「富贵不能淫，贫贱不能移，威武不能屈，此之谓大丈夫」（《滕文公下》2）
- 「人之有德慧术知者，恒存乎疢疾」——《尽心上》，困境出智慧
→ 揭示：道德不靠压抑维持，靠「养」——像养生命体一样养人格力量。

### 6. 反求诸己与求放心
- 「行有不得者，皆反求诸己」（《离娄上》）
- 「学问之道无他，求其放心而已矣」（《告子上》）——学问=找回走失的心
- 「尽其心者，知其性也；知其性，则知天矣」（《尽心上》）——内在性的形上学

## 核心术语表

| 术语 | 定义要点 |
|------|---------|
| 四端 | 每人与生俱来的四个道德萌芽（恻隐/羞恶/辞让/是非） |
| 浩然之气 | 由道义长期滋养而成的人格能量，「集义所生，非义袭而取」 |
| 良知良能 | 「不虑而知」「不学而能」的先天道德能力（尽心上） |
| 仁政 | 以性善为地基、以恒产为起点的治理方案 |
| 大丈夫 | 富贵不淫贫贱不移威武不屈的人格标准 |
| 经权 | 原则（经）与变通（权）的结构——「嫂溺，援之以手者，权也」（离娄上） |

## 与孔子的差异（自我定位）
- 孔子言仁，孟子加「义」并与利对峙——锋芒更锐
- 孔子罕言性，孟子道性善——把地基显式化
- 孔子「君君臣臣」，孟子「君为轻」——从角色伦理推进到合法性批判
- 自我定位：「乃所愿，则学孔子也」（《公孙丑上》）——但「予岂好辩哉？予不得已也」（滕文公下）
