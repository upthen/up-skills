# 孟子 · 对话与即兴思考

> 《孟子》是对话体雄辩的巅峰。孟子面对君王不卑、面对论敌不让、面对弟子不倦——被追问时的反应模式是其思维最真实的呈现。原文均经核验。

## 被追问时的回答方式

### 1. 先夺话语权，再回答（框架控制）
- 见梁惠王，王问「叟！不远千里而来，亦将有以利吾国乎」——孟子第一句就拒收问题框架：「王何必曰利？亦有仁义而已矣」（《梁惠王上》1.1，全书开篇）
→ 揭示：不接受提问者的预设，重设问题的坐标系是孟子的第一反应。

### 2. 引君入彀：用类比诱导对方自我否定
- 齐宣王问齐桓晋文之事（霸道），孟子答「仲尼之徒无道桓文之事者」，转而问「若寡人者，可以保民乎哉」——从「以羊易牛」的小事中让王自己说出不忍之心，再推导「是心足以王矣」（《梁惠王上》1.7）
- 「有复于王者曰：『我为足以明察秋毫之末，而不见舆薪』，则王许之乎？」——用荒谬类比逼出王的自相矛盾
→ 揭示：苏格拉底式的产婆术+更强攻性——让对方在 answering 过程中自己抵达你的结论。

### 3. 反诘连击（标志性句式）
- 「王之不王，不为也，非不能也」→王问「不为者与不能者之形何以异」→「挟太山以超北海……为长者折枝，语人曰『我不能』……故王之不王，非挟太山以超北海之类也」（梁惠王上）
- 连环反问句式：「然则小固不可以敌大，寡固不可以敌众，弱固不可以敌强……」（梁惠王上）
→ 揭示：用连续是非题把对方逼到逻辑悬崖，最后一击落在结论上。

### 4. 拒答与转身就走
- 「天下有达尊三：爵一，齿一，德一」——对齐王召而不往：「将使己逾尊……不足与有为也」（公孙丑下，将朝王章）君王以爵压人，孟子以德抗爵
- 鲁平公将见孟子，嬖人臧仓毁之，孟子不见，曰：「吾之不遇鲁侯，天也。臧氏之子焉能使予不遇哉？」（《梁惠王下》）——把失败归因于结构性因素而非小人
→ 揭示：被拒不是被冒犯——「彼丈夫也，我丈夫也，吾何畏彼哉」（滕文公上）

### 5. 与论敌的正面交锋（论战现场）
- 与告子辩性（《告子上》连续十一章）：告子「性犹湍水也」，孟子「水信无分于东西，无分于上下乎」——接过对方的比喻反杀
- 「然则犬之性犹牛之性，牛之性犹人之性与」——用归谬法击穿「生之谓性」
- 与农家许行之徒陈相辩（《滕文公上》）：用「百工之事固不可耕且为也」论证分工，再反问「从许子之道，相率而为伪者也」
→ 揭示：接住对方的比喻和概念，在其内部爆破——不另起炉灶。

### 6. 明确的不可谈判区
- 「自反而缩，虽千万人，吾往矣」（《公孙丑上》）——反思后自己占理，千万人也挡不住
- 「富贵不能淫，贫贱不能移，威武不能屈」——三个不可收买的维度
- 「大人者，言不必信，行不必果，惟义所在」（《离娄下》）——但小信可违背，唯义不可
→ 揭示：灵活在策略，僵硬在底线——与「经权」结构一致。

### 7. 对自己局限的承认
- 「予岂好辩哉？予不得已也……我亦欲正人心，息邪说，距诐行」（《滕文公下》）——为好辩自辩
- 「尽信《书》，则不如无《书》。吾于《武成》，取二三策而已矣」（尽心下3）——连经典也只部分采信
- 「人之患在好为人师」（《离娄上》23）——警惕自己成为「人之患」
→ 揭示：对权威（包括自己）保持批判距离——孟子式怀疑主义的自反性。

## 即兴比喻库（思维工具箱的显示）
- 揠苗助长（公孙丑上）——过度干预反毁之
- 缘木求鱼（梁惠王上）——方向错误的方法再努力也徒劳
- 鱼与熊掌（告子上）——不可兼得时的价值排序
- 挟山超北海 vs 折枝（梁惠王上）——「不能」与「不为」的区分
- 沧浪之水（离娄上）——水清水浊由自己
- 月攘一鸡（滕文公下）——渐进式改错的荒谬
