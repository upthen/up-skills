## 4.1 批评体文风：《海岳名言》的断言式毒舌

### 4.1.1 文体特征：三无——无论证、无让步、无商量

《海岳名言》全篇由短促断句构成，判断一律下死语。通读可归纳其句式骨架：**「X + 一字贬语 + 死刑判决」**，从不出现「似」「或」「殆」「愚以为」之类缓冲词。与之对照，黄伯思《法帖刊误》驳他时反而逐条考据、引证碑帖——两种文风恰成两极（见 04 文件）。

- 「颜鲁公行字可教，真便入俗品。」——对颜真卿：行书勉强，楷书直接判死刑。[一手核验] [来源 https://zh.wikisource.org/wiki/海岳名言]
- 「柳公权师欧，不及远甚，而为丑怪恶札之祖。自柳世始有俗书。」——判柳公权为「丑怪恶札之祖」，并给整个时代定罪：「自柳世始有俗书」。[一手核验] [来源同上]
- 「欧阳询道林之寺，寒俭无精神。」——四个字「寒俭无精神」判完欧阳询。[一手核验] [来源同上]
- 「丁道护欧、虞，笔始勾，古法亡矣。」——一句之内判了三个人加一个时代：「古法亡矣」。[一手核验] [来源同上]
- 「薛稷书慧普寺」讥其大字「笔笔如蒸饼」，并顺手连杜甫一起清算：「信老杜不能书也。」[一手核验] [来源同上]——注：因薛书而疑杜甫鉴赏力，毒舌的连带伤害。
- 「李邕脱子敬体，乏纤浓。」「徐浩晚年力过，更无气骨」、斥徐浩字「犹吏楷也」。[一手核验] [来源同上]
- 张旭被处理为「谬论」来源：「大字促令小，小字展令大」是「张颠教颜真卿谬论」。[一手核验] [来源同上]
- **关于怀素**：《海岳名言》通行本中未核到骂怀素的句子（通行归因的「怀素草书不足观」类语句，未核到原文）。注意：米芾对张旭怀素一路的贬斥在《宝晋英光集》论书诗中另有表述（「草书若不入晋人格，辄徒成下品」——此句通行归因为米芾论书，未在维基文库核到原文，存疑待查）。[区分：他说的/存疑的]

### 4.1.2 「勒排描画刷」：御前一对一毒舌全表

徽宗问本朝以书名世者数人，米芾当场逐人下四字判词 [一手核验] [来源 https://zh.wikisource.org/wiki/海岳名言]：

| 对象 | 判词 | 隐含指控 |
|---|---|---|
| 蔡襄 | 「勒字」 | 刻意用力，做出来的字 |
| 沈辽 | 「排字」 | 排布安排，设计的字 |
| 黄庭坚 | 「描字」 | 描画出来的字 |
| 苏轼 | 「画字」 | 画的不是写的 |
| 米芾自己 | 「臣书刷字」 | 一刷而过——速度、力量、不假安排 |

要点（我推断的）：
1. 四个判词全是贬义动词——连当面称「老师」的苏轼也是「画字」；唯独给自己的「刷」是中性偏炫技的自供。
2. 这段对话发生在御前（对话场景另见《春渚纪闻》卷七「米元章遭遇」条，情节为艮岳书屏+索砚），当面毒舌而不顾政治后果——其批评的非策略性、纯度。
3. 「刷字」一词是米芾全部笔法学的自我隐喻：八面出锋、迅疾、一次成形。「我独有四面」（「善书者只得一笔，我独有四面」[一手核验] [来源 https://zh.wikisource.org/wiki/宣和書譜_(四庫全書本)/卷12]）与之互证。

### 4.1.3 同一个人的两副面孔（与4.1.1对照，狂与谄并存的原始样本）

同一部《海岳名言》里写下的私人判词：「蔡京不得笔，蔡卞得笔而乏逸韵。」[一手核验] [来源 https://zh.wikisource.org/wiki/海岳名言]
而据蔡绦《铁围山丛谈》卷四：蔡京问当世能书者几人，米芾答「自晚唐柳，近时公家兄弟是也」（当面推蔡京父子），再问其次，才说「芾也」。[二手核验] [来源 https://zh.wikisource.org/wiki/鐵圍山叢談/卷四]
→ 表达规则（我推断的）：**私下判词见真我，当面语境见策略**。同一对象、两个判词系统并存，不调和。

## 4.2 自我表述：绝对自信与耍赖式无赖，同一张嘴

### 4.2.1 自陈家法时的自信

- 「壮岁未能立家，人谓吾书为集古字，盖取诸长处，总而成之。既老始自成家，人见之，不知以何为祖也。」[一手核验] [来源 https://zh.wikisource.org/wiki/海岳名言]——把旁人的嘲讽（「集古字」）直接收编为自我叙事，终点是「不知以何为祖」的合法化宣言。
- 自述梦中得古衣冠人授摺纸书，「书法自此差进」；且特意记下权臣反应：「蔡元长见而惊叹」、章子厚「独称其行草」。[一手核验] [来源同上]——自信表达的方式之一是转述名人的惊讶。
- 「智永砚成臼，乃能到右军。」——用别人的苦功给自己立法。[一手核验] [来源同上]
- 「功名皆一戏，未觉负生平。」（《题所得蒋氏帖》）[一手核验] [来源 https://zh.wikisource.org/wiki/寶晉英光集]——把功名看轻来抬高书道，语气是平衡过的自负。
- 「要之皆一戏，不当问拙工。意足我自足，放笔一戏空。」（《答绍彭书来论晋帖误字》）[一手核验] [来源同上]——「意足我自足」：审美主权的绝对宣示，是我方标准、不容上诉。

### 4.2.2 求帖时的无赖语言（耍赖的技术谱系）

米芾求帖用语的特征是：**把交易推到对方无法拒绝的戏剧极限**。
- 王略帖事件（舟中向蔡攸索《王略帖》）：「若不见从，某即投此江死矣」，随后「因大呼据船舷欲堕，攸即与之」。[传闻（宋人笔记，注引「志林麈谈」）] [来源 https://zh.wikisource.org/wiki/六藝之一録_(四庫全書本)/卷162]——注意与米芾自记矛盾：米芾《跋王右军帖》自述「力以十五万购之……信天下第一帖也」[一手核验] [来源 https://zh.wikisource.org/wiki/寶晉英光集]；《石林燕语辨》卷十已指出「据米芾所记，王略帖八十二字，乃是以钱十五万得之」，与投江故事两歧。[二手核验] [来源 https://zh.wikisource.org/wiki/石林燕語辨/卷10] → 他自己的叙述版本竟然是「花大钱买的」，掉江故事更像朋友圈段子。矛盾保留。
- 对王诜借研山不还，跋语原文：「王诜借山去已一月」，米芾「遂百简索，不还」——发一百封短信催债。[一手核验] [来源 https://zh.wikisource.org/wiki/寶晉英光集]——「百简索」三字是最生动的米芾式催讨：不翻脸，用数量淹死你。
- 借观沈传师《道林诗》牌，「借留书斋半岁」以摹拓 [一手核验] [来源 https://zh.wikisource.org/wiki/寶章待訪錄]；蔡绦记更猛版本：为微官游湖南时「舣舟湘江，就寺主僧借观，一夕张帆携之遁」，寺僧讼官才追回。[二手核验] [来源 https://zh.wikisource.org/wiki/鐵圍山叢談/卷四]——借→赖→遁，一整套流程。
- 交易时以坠水为筹码：「又尝与客泛采石矶，饮酒未酣，忽值所蓄书一箧，起立曰：『可怕！』遽坠水，援之，获免。因请易他所蓄，莫肯予，则又屡作此计，人皆知之，无肯与易者。」（《京口耆旧传》卷二）[二手核验] [来源 https://zh.wikisource.org/wiki/京口耆舊傳_(四庫全書本)/卷2]——同一招用太多次被人识破，是「无赖的通货膨胀」，极具喜剧性。
- 御前索砚：书毕捧砚跪请「此研经赐臣芾濡染，不堪复以进御，取进止」，徽宗大笑赐砚，米芾「抱砚趋出，余墨沾渍袍袖而喜见颜色」。（《春渚纪闻》卷七「米元章遭遇」）[二手核验] [来源 https://zh.wikisource.org/wiki/春渚紀聞/卷07]
- 书信下拜：客从窗隙窥其作书，「至『芾再拜』，即放笔，敛衿端笏，两揖而止」。（《京口耆旧传》卷二）[二手核验] [来源同上]

### 4.2.3 「辩颠」：被指疯时的自我辩护文体

被言官以「颠」弹劾后，米芾写信给蔡京诉流落之状，「遂画一艇子行间」；又遍告执政自辩：「举主数十百人……一无有以颠荐者」——世上传其《辩颠帖》。（《铁围山丛谈》卷四）[二手核验] [来源 https://zh.wikisource.org/wiki/鐵圍山叢談/卷四]
→ 要点（我推断的）：他对「颠」的指控极度敏感、认真走程序自辩——「颠」不是无意识，是一个需要管理的人设资产。

## 4.3 自作诗文的风格：苦吟、造语、仿晋人

### 4.3.1 苦吟与梦中得句

- 《频于梦中作宫词何也？漫成一首》——题目本身就是苦吟者的自嘲记录；梦中句「满院红芳减复添，清微风细入重帘」。[一手核验] [来源 https://zh.wikisource.org/wiki/寶晉英光集]
- 苏轼形容他「作书日千纸，平生自苦谁与美」——苦功的旁观者证词。[一手核验（苏轼诗）] [来源 https://zh.wikisource.org/wiki/次韻米黻二王書跋尾二首]
- 「一日不书，便觉思涩。」[一手核验] [来源 https://zh.wikisource.org/wiki/海岳名言]——手艺人的日课自述。

### 4.3.2 造语：不蹈袭前人一字

- 《宣和书谱》官方评语：「善属文，作韵语不蹈袭前人一字。」[一手核验（宣和内府评）] [来源 https://zh.wikisource.org/wiki/宣和書譜_(四庫全書本)/卷12]
- 仿古实验：楚辞体《壮观》（真州城北）：「临南山猗，陟北岫，抚壮胜猗，遗万古。」通篇「猗」字句。[一手核验] [来源 https://zh.wikisource.org/wiki/寶晉英光集]
- 仿晋人的实绩主要在书法（「入晋魏平淡」自述，见4.4），诗题跋中直接咏晋帖：《题唐摹子敬范新妇帖三首》《太师行寄王太史彦舟》（「治乱悠悠八百年……端使米老铺案间」）[一手核验] [来源同上]

### 4.3.3 《苕溪诗》《蜀素帖》的语言气质

- 苕溪诗、蜀素帖为传世墨迹（分别书于元祐三年1088、元祐三年前后），其文本不入《宝晋英光集》正卷。诗句核验情况：本次调研未从维基文库核到全文；通行引用如「松竹留因夏，溪山去为秋」等句，通行归因，未核到原文。[区分：存疑待核]
- 可靠的旁证是其题画诗审美：「画号为真理或然，悠悠觉夣本同筌。」（《题李成画》）[一手核验] [来源 https://zh.wikisource.org/wiki/寶晉英光集]——诗风同书风：流动、翻侧、不主故常，而理语与庄禅语掺半。

## 4.4 词汇特征表：他靠哪几个字思考

从一手文本统计其高频判断词（我推断的归纳，例证均一手核验）：

| 词 | 用法与例证 | 来源 |
|---|---|---|
| **真** | 「真趣」：「裴休率意写碑，乃有真趣，不陷丑怪」；「沈传师变格，自有超世真趣」；「学书须得趣」；「必须真迹观之，乃得趣」——「真/迹/趣」三位一体，是他的认识论核心词 | 海岳名言 [一手核验] |
| **俗** | 最高刑名词：「真便入俗品」「自柳世始有俗书」「印章俗」；画论「装堂画俗」（见4.4.1俗字表） | 海岳名言、画史 [一手核验] |
| **格/变格** | 「沈传师变格」；「书至隶兴，篆籀法亡」——「格」是可变的历史范畴，非永恒标准 | 海岳名言 [一手核验] |
| **得笔/不得笔** | 「蔡京不得笔，蔡卞得笔而乏逸韵」「智永有八面，已少钟法」；「得笔」=掌握笔法的核心技术认证词，可授予可吊销 | 海岳名言 [一手核验] |
| **势** | 「以势为主」通篇笔势论：「篆籀各随字形大小……隶乃始有展促之势，而三代法亡矣」 | 海岳名言 [一手核验] |
| **天真/意外** | 「把笔轻，自然手心虚，振迅天真出于意外，所以古人书各各不同」；「天真」是从笔的物理里「意外」长出来的，不是设计出来的 | 宝晋英光集 [一手核验] |
| **平淡** | 「入晋魏，平淡」；画论「董源平淡天真多」——平淡是价值终点，与「天真」合流 | 宝晋英光集、画史 [一手核验] |
| **奴书** | 「若一一相似，则奴书也」——模仿的死刑词，与「集古字」的辩证统一（集古≠奴书，似古才是） | 宝晋英光集 [一手核验] |

### 4.4.1 「俗」字判定表（《画史》，一手核验 [来源 https://zh.wikisource.org/wiki/畫史]）

- 「山水李成只见两本……松石……枝枝奇怪」——奇即褒。
- 赵令穰（大年）「又作小轴清丽」——宗室盟友的画也进他的词库。
- 「鉴阅佛像故事图，有以劝戒为上，其次玩好；……收画者亦目有赏鉴」——鉴定次序观。
- 印章：「『贞观』『开元』小印……印记虽多，俱俗」？——注意：此句未核到原文原文为「古印章多俗」？保守引用核到的：「唐印『贞观』……多俗」（未核到原句，标存疑）。
- 「装堂画」不入其目（「屏风上画……不入吾目」表述通行，未核到原句，存疑）。
- 「葛洪天台观飞白为大字之冠，古今第一」「萧诚太原题名，唐人无出其右」——毒舌的反面：给出「古今第一」时的同等果断。[一手核验] [来源 https://zh.wikisource.org/wiki/海岳名言]

## 4.5 确定性表达：审美判断的绝对语气

- 判「天下第一」成瘾：「天下法书第一」（苏之才《恒公至洛帖）、「信天下第一帖也」（王略帖）、「古今第一」（葛洪飞白）。[一手核验] [来源 海岳名言/宝晋英光集]
- 排他性总数判断：「本朝以书名世者数人」（御前对话把整个本朝书法压缩为一张五人名单，他一个人占「刷」）。[一手核验]
- 修辞上的除法句式：「古法亡矣」（一句除掉一个时代）、「自柳世始有俗书」（把堕落起点精确到人）。[一手核验]
- 对照组：同时代严肃学者黄伯思批评米芾「概举其目，疏略甚多」、四库提要评米论书「多以意断制，罕所考证」[一手核验（四库提要语）] [来源 https://zh.wikisource.org/wiki/法帖刋誤_(四庫全書本)/卷上]——「意断制」正是其确定性的方法论名称：以直觉判决，不以考证支撑。
- 我推断的：米芾的绝对语气不是修辞缺陷而是认识论立场——「得笔」者有裁判权；考证派（黄伯思）与直觉派（米芾）的分歧是宋代鉴定学的两条路线之争。

## 4.6 幽默方式：行为艺术式癫狂 + 文字狂谑

### 4.6.1 行为幽默（他的喜剧都在动作里）

- **拜石**：无为军州治见奇丑巨石大喜「此足以当吾拜！」「具衣冠拜之，呼之为兄。」[一手核验] [来源 https://zh.wikisource.org/wiki/宋史/卷444]——幽默结构：用最高礼节对待最低身份者（石头），庄谱反差。
- **洁癖**：「好洁成癖，至不与人同巾器。」[一手核验] [来源同上]；《京口耆旧传》卷二：「然至恶言及人间秽浊事，闻者绝倒」？——此句未核到原文，保守。另银斗洗金（用银制小斗量水浇洗）故事通行出自宋人笔记（如《鸡肋编》），本次未核到原文，标「通行归因，未核到原文」。
- **御前索砚**（怀砚墨淋漓而出）、《**芾再拜**》书信下拜、**蝗灾批牍**：邻县移文责雍丘驱蝗不力，米芾「方与客饭，视牒大笑」，批诗回复：「蝗虫元是空飞物，天遣来为百姓灾。本县若还驱得去，贵司却请打回来。」[一手核验] [来源 https://zh.wikisource.org/wiki/春渚紀聞/卷02]（卷次见春渚纪闻杂记）——用一首打油诗把公文战变成荒诞剧，公务照办、面子不输。

### 4.6.2 文字狂谑

- 与苏轼互怼：苏轼赠诗调侃「巧偷豪夺古来有，一笑谁似痴虎头」（把他比顾恺之的痴）[一手核验] [来源 https://zh.wikisource.org/wiki/次韻米黻二王書跋尾二首]；「画地为饼未必似，要令痴儿出馋水」[一手核验] [来源同上]——苏米交谊的幽默底色是互相封「痴」。
- 黄庭坚：「沧江静夜虹贯月，定是米家书画船。」（《戏赠米元章》）[一手核验] [来源 https://zh.wikisource.org/wiki/戲贈米元章]——朋友眼中的米芾生活本身就是段子。
- 自黑式命名：行船挂牌「米家书画船」（《诗话总龟》后集卷五十：「揭一牌于行舸之上曰米家书画船」；《京口耆旧传》卷二记其自谓「以书乃为身外物」？——后半句未核到，保守）。[二手核验] [来源 https://zh.wikisource.org/wiki/詩話總龜_(四庫全書本)/後集卷50]

### 4.6.3 幽默的三定律（我推断的）

1. **庄谱错位**：把极端的严肃（衣冠拜、端笏两揖）投入不相称对象（石、书信抬头、砚台）。
2. **以数量取胜**：百简索帖、屡次坠水「人皆知之」——重复到荒诞。
3. **从不自嘲艺术、只自嘲身段**：可以拜石、可以跳江，但「臣书刷字」「我独有四面」从不打折。
