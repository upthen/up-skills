## 1. 黄州书信：苦难中的"生活工程学"

### 1.1 答秦太虚书——把贫穷变成可管理的系统【他说】
全文核验 [一手]。关键材料：
1. **现金流管理法**：「初到黃，廩入既絕，人口不少，私甚憂之。但痛自節儉，日用不得過百五十。每月朔便取四千五百錢，斷為三十塊，掛屋梁上，平旦用畫乂挑取一塊，即藏去乂，仍以大竹筒別貯用不盡者，以待賓客，此賈耘老法也。」
2. **预期管理**：「度囊中尚可支一歲有餘，至時別作經畫，水到渠成，不須預慮。以此，胸中都無一事。」
3. **资源清单法**（对岸武昌的山水、王生杀鸡炊黍、潘生村酒、柑橘椑柿、大芋、鱼蟹不论钱、胡定之万卷书可借……逐项列出）后总结：「太虛視此數事，吾事豈不既濟矣乎！」
4. **风险转化**：「已借得本州大慶觀道堂三間，冬至後當入此室，四十九日乃出。自非廢放，安得就此。太虛他日一為仕宦所縻，欲求四十九日閒，豈可復得耶？當及今為之。」——贬谪被重估为**闭关修炼的难得窗口**。
5. **表达自律**：「得罪以來，不復作文字，自持頗嚴，若復一作，則決壞藩墻，今後仍復袞袞多言矣。」——狱后对写作冲动的自我管控。
6. 收尾：「欲與太虛言者無窮，但紙盡耳。展讀至此，想見掀髯一笑也。……夜中微被酒，書不成字，不罪！不罪！」
- 【我推断】这是他逆境操作系统的完整展示：量化预算→延长弹药周期→列资源清单→重估损失为收益→对危险习惯（写作）设硬约束。**注意顺序：先解决系统，再谈心情**（"胸中都无一事"是预算表做完了的结果，不是前提）。

### 1.2 答李端叔书——社交死亡后的自我审计【他说】
全文核验 [一手]。关键材料：
1. **身份消融的快感**：「得罪以來，深自閉塞，扁舟草履，放浪山水間，與樵漁雜處，往往為醉人所推罵，輒自喜漸不為人識。」
2. **人情实况**（无美化）：「平生親友無一字見及，有書與之亦不答。」
3. **自我病理报告**：「木有癭，石有暈，犀有通，以取妍於人，皆物之病也。謫居無事，默自觀省，回視三十年以來所為，多其病者。」——把名声理解为**病态增生组织**（瘿/晕/通皆为物之病，却正因病害而取悦于人）。
4. **对成名的清算**：「軾少年時，讀書作文，專為應舉而已。……故每紛然誦說古今，考論是非，以應其名耳。」自嘲「所謂齊虜以口舌得官，真可笑也」。
- 【我推断】被追问/被打击时的反应模式A：**先于他人否定自己身上被攻击的部分**（名声、言辩），且用病理比喻而非道德忏悔——他不认罪，他做手术。

### 1.3 答程天侔（儋州）——绝境清单与最低限度哲学【他说】
全文核验 [一手]。关键材料：
1. **生存实况直录**：「此間食無肉，病無藥，居無室，出無友，冬無炭，夏無寒泉」，紧接「惟有一幸，無甚瘴也」——六个"无"后面立刻接一个"幸"。
2. **自处总纲**：「尚有此身，付與造物，聽其運轉，流行坎止，無不可者。故人知之，免憂。」
3. 丧孙之痛也直录：「悲愴久之，今則已矣。」
4. 收尾日常化：「夏熱，萬萬自愛。」
- 【我推断】三封书信（黄州→儋州）显示同一模式的升级版：黄州还能"管理"苦难（预算表），儋州只能"交付"苦难（付与造物）。**从控制到交托**，是他的逆境算法在极端条件下的降级运行，且降级后幽默仍在（"惟有一幸无甚瘴也"）。

## 2. 狱中与危局：1079年乌台诗案的反应实录

### 2.1 狱中寄子由【他说】
- 「聖主如天萬物春」起句（先向体制表忠诚的求生策略）；「是處青山可埋骨，他年夜雨獨傷神」；「與君世世為兄弟，更結人間未了因」（文库本作"人間"，通行作"來生"，异文已核）。[一手]
- 其二：「夢繞雲山心似鹿，魂飛湯火命如雞。眼中犀角真吾子，身後牛衣愧老妻。百歲神遊定何處，桐鄉知葬浙江西。」[一手]
- 【我推断】死亡概率最高时的思维清单排序：1) 兄弟（情感核心）；2) 妻儿生计（愧疚）；3) 葬地从俭（后事）；4) 对君主的表态（程序）。恐惧被如实写出（心似鹿、命如鸡），**不装旷达**——与他后来文字中的旷达并存，说明旷达不是性格，是事后处理技术。
- 【别人说】苏辙墓志铭记此案：「既付獄，必欲寘之死，鍛鍊久之不決，上終憐之。」并解释其写讽诗的动机：「見事有不便於民者，不敢言、亦不敢默視也，緣詩人之義，託事以諷，庶幾有補於國。」[一手·墓志铭]
- 【别人说】墓志铭又记：御史诬奏时「公未嘗以一言自辯，乞外任避之」。[一手·墓志铭] —— 不自辩是其被攻击时的一贯姿态（1071谢景温案、1079诗案两次一致）。

## 3. 《东坡志林》即兴片段：未经修饰的念头

### 3.1 记游松风亭（惠州）
「良久忽曰：此間有甚麼歇不得處！」「由是如掛鉤之魚，忽得解脫。」随即推广到战场绝境也可"熟歇"。[一手·志林卷一]
- 【我推断】志林价值在于**思考过程的裸露**：走累→焦虑→自我反问（口语！带"甚么"）→顿悟→推广。这四步是可复原的思维时序，比成品文章更能代表其真实认知节奏。

### 3.2 记游庐山（元丰七年）
初入庐山"不作诗"的自我约束被僧俗认出而打破，最终《题西林壁》后自断："僕廬山詩盡於此矣"（志林大意核验）。[一手·志林卷一]
- 【我推断】"尽于此"=知道边际在哪、主动停止。与自评文"止于不可不止"互证。

### 3.3 记承天寺夜游（元丰六年）
见维度1 §4.5。"闲人"自我定义是即兴社交（找张怀民）的副产品。[一手]

## 4. 同时代人记录：别人眼里的他

### 4.1 苏辙《亡兄子瞻端明墓志铭》（1112年前后作，弟弟视角）【别人说】
全部核验 [一手·墓志铭]。关键条目：
1. **童年范滂对话**（价值观安装时刻）：母读《范滂传》慨叹，苏轼侍侧曰：「軾若為滂，夫人亦許之否乎？」母曰：「汝能為滂，吾顧不能為滂母耶？」「公亦奮厲有當世志。」
2. **欧阳修之叹**（1057）：欧公得其文「驚喜，以為異人，欲以冠多士，疑曾子固所為……乃寘公第二」；后以书语梅圣俞：「老夫當避此人，放出一頭地！」
3. **思想传记**（苏轼精神史的最权威一手概括）：「初好賈誼、陸贄書，論古今治亂，不為空言；既而讀莊子，喟然歎息曰：『吾昔有見於中，口未能言，今見莊子，得吾心矣！』」→ 黄州「杜門深居，馳騁翰墨，其文一變，如川之方至，而轍瞠然不能及矣」→「後讀釋氏書，深悟實相，參之孔老，博辯無礙」→晚年海南成三书（易傳/論語說/書傳），「撫之曰：今世要未能信，後有君子當知我矣。」
4. **人格鉴定**（弟弟的最终评语）：「見善稱之如恐不及，見不善斥之如恐不盡，見義勇於敢為而不顧其後，用此數困於世，然終不以為恨。」
5. **临终**（1101）：「獨以諸子侍側曰：吾生無惡，死必不墜，慎無哭泣。以怛化問以後事，不答，湛然而逝。」
6. **死亡的社会面**：「吳越之民相與哭於市……太學之士數百人，相率飯僧惠林佛舍。嗚呼！斯文墜矣，後生安所復仰？」
7. **黄州改名仪式**：「幅巾芒屩，與田父野老相從溪谷之間，築室於東坡，自號東坡居士。」
8. **神宗手札**（1084量移汝州时）：「蘇軾黜居思咎，閱歲滋深。人材實難，不忍終棄。」
9. **调解章惇护司马光**（元祐初）：章惇以谑侮困司马光，苏轼引许靖故事劝章惇「君實時望甚重……況君實乎？」章惇以为然。[墓志铭；宋史卷338同记，文字略异：「軾舊善司馬光、章惇……軾謂惇曰：司馬君卽時望甚重……」——两处文字小异，照录不调和]
- 【我推断】墓志铭第4条是全部材料中最重要的人格侧写："数困于世，终不以为恨"——他自己（及至亲）都清楚代价清单，且明确表态**不进行成本追偿**。

### 4.2 《宋史》卷338中的对话实录【别人说】
- 与王安石并存期的一句刻薄玩笑：「安石曰……人須是知行一不義，殺一不辜，得天下弗為，乃可。軾戲曰：今之君子，爭減半年磨勘，雖殺人亦為之。安石笑而不言。」[二手·正史]
- 对神宗的"三患"直谏与神宗反应：「軾曰：……但患求治太急，聽言太廣，進人太銳。願鎮以安靜……神宗悚然。」[二手·正史]
- 宣仁后问对（元祐）：后曰「此先帝意也。先帝每誦卿文章，必歎曰：奇才，奇才！但未及進用卿耳」——「軾不覺哭失聲，宣仁后與哲宗亦泣」。[二手·正史]
- 处置溃卒的镇定：「軾投其書不視，曰：必不至此。散卒聞之，少安，徐使人招出戮之。」[二手·正史]
- 高丽使事件：「高麗於本朝稱臣，而不稟正朔，吾安敢受！」使者「亟易書稱熙寧，然後受之，時以為得體」。[二手·正史·墓志铭两记]
- 手实法抗命：对提举官曰「今出於司農，是擅造律也」，提举官驚曰「公姑徐之」，未几法罢。[二手·正史]
- 【我推断】宋史选录的对话呈现另一个侧面：行政现场的苏轼是**延迟反应大师**（投书不视/徐使人/姑徐之），与文字里的"遇事则发"（思堂记）形成人格两面——笔快、手慢。这个不对称在其被追责时救过他（不自辩、徐图之），也害过他（诗快于政）。

### 4.3 费衮《梁溪漫志》卷四【别人说】
1. **"一肚皮不入时宜"（朝云对话）**——原文核验：「東坡一日退朝，食罷捫腹徐行，顧謂侍兒曰：汝輩且道是中有何物？一婢遽曰：都是文章。坡不以為然。又一人曰：滿腹都是識見。坡亦未以為當。至朝雲乃曰：學士一肚皮不入時宜。坡捧腹大笑。」[二手·梁溪漫志卷04]
   - **重要矛盾记录**：通行说法多归此条于赵令畤《侯鯖錄》且引作"一肚子不合时宜"。本次在文库全文检索"侯鯖錄 不入時宜/不合時宜"均**未命中侯鲭录**；核到的是《梁谿漫志》卷四"侍兒對東坡語"条，字作「一肚皮不入時宜」。引用时应改标费衮《梁溪漫志》。[一手核验的原文 + 二手通行归因的矛盾]
2. **儋州受敬与株连**：「東坡之在儋，儋守張中事之甚至，且日從叔黨（苏过）棋以娛東坡，洎張解官北歸，坡凡三作詩送之。……張竟以此坐謫。」[二手]
3. **避祸的自嘲诗**（崇宁党祸时）：绍圣中所作《上清储祥宫碑》被磨去改命蔡京撰，东坡"玉局遗文"中有意作淮西段文昌故事诗自嘲，「其題云：紹聖中得此詩於沿流館中，不知何人作也，戲錄之……此詩乃東坡自作，蓋寓意儲祥之事，特避禍故託以得之」。[二手·费衮的判断]
4. **柳展如排次岭南文**：东坡自海南归，令外甥柳展如评第其岭南文，展如举《天庆观乳泉赋》第一，坡「歎息以為知言」。[二手]
5. **石屋洞题名被磨**（崇宁党禁实物证据）：杭州石屋洞熙宁六年苏轼等题名25字，「內東坡姓名磨去，僅存彷彿，蓋崇寧黨禍時也」。[二手]

### 4.4 惠洪《冷斋夜话》等（经《苕溪渔隐丛话》转引）【别人说】
1. **黄庭坚惠州寄诗**：「子瞻謫嶺南，時宰欲殺之。飽吃惠州飯，細和淵明詩。彭澤千載人，子瞻百世士。出處雖不同，風味乃相似。」[二手·冷斋夜话（转引）；黄庭坚原诗]
2. **"已死"传闻下的黑色幽默**（1100-01北归）：南昌太守叶祖洽曰：「世傳端明已遊道山，今尚爾遊戲人間邪？」坡曰：「途中見子厚（章惇），故返回耳。」——答语拿正在被贬雷州的政敌章惇开玩笑，说自己"本已上天，路上碰到章惇就回来了"。[二手·冷斋夜话]
   - 【我推断】这是其幽默的本质样本：**用自贬（我本来已经死了）+ 现挂（贬敌）完成对死亡传闻的消解**。攻击性为零（未落井下石），锋利性满分。注：章惇时贬雷州，苏轼北上确经其境；此语与另一处记载"苏轼致章惇子章援书不念旧恶"（本次未核到该书信原文，标未核）方向一致。
3. **王直方诗话**：山谷读东坡扬州和饮酒诗至「前山正可數，後騎且勿驅」曰：「此老未死在。」又评：惠州《和歸田園》六首「乃與淵明無異」。[二手]
4. **东坡论渊明**（冷斋夜话载）：「淵明詩，初視若散緩，熟視有奇趣。」[二手]

### 4.5 苏过《志隐》与父亲的反应【别人说+他说】
宋史卷338（苏过附传）：初至海南，苏过作《志隱》，「軾覽之曰：吾可以安於島夷矣。因命作《孔子弟子別傳》。」[二手·正史]
- 【我推断】"安于岛夷"的**实现方式**是儿子的文章+父亲的认可仪式——家庭的写作分工是他贬谪期的支撑结构（苏过独随侍惠州儋州）。

## 6. 被打击时的反应模式（跨材料归纳，我推断）

综合1071（谢景温诬奏）、1079（诗案下狱）、1080-84（黄州）、1094-97（惠州儋州）、1100-01（死亡传闻与临终）五段证据：
1. **第一动作：不自辩**（"未嘗以一言自辯"）[一手·墓志铭]
2. **第二动作：量化或清单化处境**（答秦太虚预算表；答程天侔六无一幸）[一手]
3. **第三动作：重估损失为收益**（"自非廢放，安得就此"；"問汝平生功業，黃州惠州儋州"）[一手]
4. **第四动作：病理化自我审查而非道德忏悔**（答李端叔）[一手]
5. **贯穿动作：幽默不间断**（各期皆有实例，见§5）
6. **底线动作：交付而不弃权**（"付與造物，流行坎止"仍写三书；"死必不墜"）[一手]
- 注意与常见叙事的差异：材料中**没有**"迅速想通"的证据；顿悟（松风亭）有明确时滞（"良久忽曰"），黄州安顿费时经年（"處之期年而貌加豐"是密州例；黄州三年才"文一变"）。【我推断】其旷达是**慢系统**，不是即时反应。
