# 曾国藩 · 他者视角与批评

> 曾国藩是中国近代史上评价两极化最严重的人物之一：「誉之则为圣相，谳之则为元凶」（章太炎语，通行归因，学界多标注出自《检论》，卷次未在线核验）。

## 同时代与亲近者的评价

### 梁启超（一手，梁著《曾文正公嘉言钞》序）
- 「岂惟近代，盖有史以来不一二睹之大人也已」
- 关键细节：「在并时诸贤杰中，称最钝拙」——最钝拙者成最大事，梁认为这是其可学性的证明
→ 修正主义视角：不像天才不可学，曾的路径普通人可复制——这也是「曾国藩热」的传播基础

### 左宗棠（对手型同僚）
- 一生相轻相敬：左常骂曾「才短」「伪」，但曾死，左送挽联（通行引用）：「谋国之忠，知人之明，自愧不如元辅」——骂了一辈子，认输在悼词
→ 揭示：其「知人」连对手都认账

### 李鸿章（学生）
- 评价其「儒缓」（反应慢）但「坚忍」（通行引用的李氏回忆）——学生的证词：慢而不可撼动

## 批评与争议（不可回避的维度）

### 「曾剃头」：严酷镇压的名声
- 长沙设审案局严刑速杀得名说；湘军克天京（1864）屠城，「曾剃头」「曾屠户」之称由是而来（维基条目多源记载）
- 章太炎「谳之则为元凶」即指此——对太平天国战争的暴力层面，历史评价持续批判
→ skill 的处理：如实保留此维度于「价值观与反模式」的张力区——理学家的仁与屠城的残酷并存于同一人，不可洗白也不可只留一半

### 天津教案（1870）：晚年的至暗评价
- 处理天津教案（民众烧教堂杀洋人后的交涉）被舆论骂「卖国」，其自辩「外惭清议，内疚神明」（日记通行引用）
- 「积年清望几于扫地」（时论）——从道德偶像到「汉奸」骂名只需一纸处理方案
→ 揭示：执行者承担结构性的两难——清流可空谈，局中人必须签

### 「曾剃头」之外的近代批判线
- 革命党人（章太炎、邹容一系）：骂其扶清延缓革命——「以一身为之障」的历史反动论
- 阶级史观时期：镇压农民起义的刽子手定位（20世纪主流史学评价）
- 1980s后：「曾国藩热」反转——传统文化人格样板、成功学对象、管理与修身的资源（《曾国藩》唐浩明小说推动的大众化）

## 现代评价的钟摆

| 时期 | 主导评价 | 动因 |
|------|---------|------|
| 晚清 | 中兴名臣/理学领袖 | 平乱之功 |
| 清末革命 | 扶清之「元凶」 | 反满革命需要 |
| 民国 | 梁启超式的可学圣人 | 人格修身的现代焦虑 |
| 革命史学 | 刽子手/反动派 | 阶级史观 |
| 1990s至今 | 修身处世楷模/管理学案例 | 传统文化回归+成功学市场 |
| 学术界 | 复杂化：洋务先驱+屠杀者+理学实践者 | 多元史学 |

→ 评价史发现：对曾国藩的评价两极且随时代翻烙饼——但**日记与家书的一手文本**（自省、尚拙、求缺）与**行为的争议面**（屠城、教案）都同样真实。任何只取一半的叙述都是宣传。

## 同侪对比
- vs 左宗棠：左是天才型（快、傲、奇），曾是庸才型（慢、忍、正）——一对互补的对照组
- vs 胡林翼：胡更灵活圆融，曾更笨拙彻底——时人并称「曾胡」
- vs 李鸿章：李得其「 practical 」不得其「恒」，曾自己评李「聪明」而虑其「无恒」（通行引用）
- vs 王阳明：同为文臣建军、同以心性之学练兵——阳明是天才的顿悟路径，曾是庸人的迭代路径（用户已有王阳明perspective，可对照使用）
