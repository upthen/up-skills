# 曾国藩 · 人物时间线

> 1811年11月26日-1872年3月12日（维基百科核验）。湖南湘乡人。历史人物，无时效性动态。

| 时间 | 事件 | 对思维的影响 |
|------|------|------------|
| 1811 | 生于湖南湘乡白杨坪，耕读之家 | 「吾家世泽」的农家底色——笨功夫的自尊来源 |
| 1826-1838 | 科举长跑：考秀才七次（前六次落榜，23岁中）；1838中进士（28岁），入翰林 | 七次落榜塑造「拙」的自我认知与「有恒」的路径依赖 |
| 1840s | 京官期：从愤青到理学家——师从唐鉴、倭仁，1842年立日课十二条 | 自省系统的安装期；1850年前官至礼部侍郎（二品） |
| 1852 | 母丧回籍；同年奉旨帮办湖南团练（夺情出山） | 文官→建军者的身份切换 |
| 1853 | 长沙严办土匪触怒官场，转衡阳练兵；湘军水师筹建 | 「不与烂体制正面冲突」的第一课 |
| 1854 | 靖港惨败，投水自尽被救；湘潭之战扭转；攻下武昌 | 第一次生死级挫折与叙事重建 |
| 1855 | 湖口再败（石达开），再度欲自尽 | 「打脱牙和血吞」的淬火期 |
| 1857 | 父丧，不待朝命回籍守制；与朝廷博弈后1858复出 | 「刚→柔」的风格切换：复出后为人处世大变（自述昔年倔强今用浑含） |
| 1860-1861 | 任两江总督；安庆内军械所（1861）创立；安庆攻坚战 | 督抚实权+洋务发端 |
| 1864 | 克天京；旋即自裁湘军2.5万人，曾国荃开缺回籍 | 「求缺」的顶峰执行 |
| 1865-1868 | 剿捻无功（李鸿章接手）；调任直隶总督 | 承认能力边界（捻战非其所长） |
| 1870 | 天津教案，「外惭清议，内疚神明」 | 晚年至暗：结构性两难的承担 |
| 1871-1872 | 回任两江；促成留美幼童（1872年成行）；1872年3月12日卒于南京 | 最后的长期投资：教育与人才 |
| 身后 | 谥文正（文人最高谥号） | 「立德立功立言」三不朽的官方认定 |

## 思想发展关键转折

1. **七次落榜（1826-1838）**：「拙」从创伤变成方法论
2. **京师修身期（1840s）**：愤青（好讥评、傲慢）→理学家（日课自省）——30岁的性格重装
3. **1853-1855 军旅淬火**：两次自杀未遂→逆商定型
4. **1857-1858 丁忧博弈**：与朝廷的权力教育→「柔」的成熟期（大脱胎换骨，其自述）
5. **1864 自裁湘军**：求缺哲学的最高执行
6. **1870 天津教案**：承担无解之局，身败而局不裂
7. **1872 留美幼童**：临终的百年布局（詹天佑等出此批）

## 身后大事
- 梁启超1916辑《曾文正公嘉言钞》——民国「曾国藩热」
- 革命史学时期批判（镇压太平天国）
- 1990s唐浩明历史小说《曾国藩》→当代大众曾国藩热（管理、修身、家训市场）
- 学术界持续研究其日记/家书的「日课自省」体系
