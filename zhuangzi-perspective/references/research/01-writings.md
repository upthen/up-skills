# 庄子 · 著作与系统思考

> 调研说明：《庄子》今本33篇（郭象删定），学界主流（Graham、刘笑敢等）：内篇7篇为庄子自著（战国中期），外杂篇为庄子后学及多家所作。蒸馏以内篇为思想主体、外杂篇（尤其秋水、至乐、天下）为佐证。原文经维基文库逐条核验。

## 自述方法论（《寓言》篇，一手）
- 「寓言十九，重言十七，卮言日出」——寓言占九成，借重之言占七成，无心之言日日出
- 这是中国文献史上罕见的「文体自觉」：庄子知道自己不直接说理，用故事让你自己撞见道理

## 反复出现的核心论点（≥3次=真信念）

### 1. 齐物：是非与标准的相对性（认识论地基）
- 「天地与我并生，而万物与我为一」（齐物论）
- 「彼亦一是非，此亦一是非」（齐物论）——各有一套是非
- 「以指喻指之非指，不若以非指喻指之非指也」（齐物论）——论辩的无穷倒退
- 「小知不及大知，小年不及大年」（逍遥游）；「以道观之，物无贵贱」（秋水）
→ 揭示：一切判断依赖视角与尺度——冲突常源于尺度差而非对错差。

### 2. 逍遥：无待的自由（终极理想）
- 「乘天地之正，而御六气之辩，以游无穷者，彼且恶乎待哉」（逍遥游）——不依赖任何条件者才真自由
- 鲲鹏与蜩鸠的对照（逍遥游）：大小之辩，但也暗示鹏亦有所待（风）
- 「至人无己，神人无功，圣人无名」（逍遥游）——自由的三个障碍：己、功、名
→ 揭示：依赖即束缚——自由度=依赖清单的长度。

### 3. 无用之用：价值标准的翻转
- 「人皆知有用之用，而莫知无用之用也」（人间世篇末）
- 樗树：「无所可用，故能若是之寿」（逍遥游）——不材之木得终其天年
- 大瓠寓言：惠子嫌葫芦太大没用，庄子说「虑以为大樽而浮乎江湖」（逍遥游）——不是无用，是想象力不够
- 「山木自寇也，膏火自煎也」（人间世）——有用导致自毁
→ 揭示：有用性本身是特定标准的产物——在标准之外，废物可以是自由。

### 4. 安时处顺：对不可改变的接受
- 「知其不可奈何而安之若命，德之至也」（人间世）
- 「适来，夫子时也；适去，夫子顺也。安时而处顺，哀乐不能入也」（养生主，老聃死一章）
- 妻死鼓盆而歌：「人且偃然寝于巨室，而我噭噭然随而哭之，自以为不通乎命」（至乐）
→ 揭示：痛苦=现实与期待的落差；把「命」（不可控结构）看清，情绪就失去了支点。

### 5. 吾生有涯：认知的有限性
- 「吾生也有涯，而知也无涯。以有涯随无涯，殆已」（养生主开篇）
- 「吾生也有涯」常被截去后半句用作劝学——原文恰恰是反对无止境追逐知识
- 「井蛙不可以语于海者，拘于虚也；夏虫不可以语于冰者，笃于时也」（秋水）——每个认知都被时空封顶
→ 揭示：认知谦卑不是美德装饰，是事实描述。

### 6. 依乎天理：顺势的技术哲学
- 庖丁解牛：「依乎天理，批大郤，导大窾……以无厚入有间，恢恢乎其于游刃必有余地矣」（养生主）
- 「所好者道也，进乎技矣」——技术的高阶是道（规律本身）
- 「是以十九年而刀刃若新发于硎」——好工具的秘密是不硬碰
→ 揭示：专家=找到事物自然纹理并顺着走的人；磨损=与纹理对着干的累积。

## 核心术语表

| 术语 | 定义要点 |
|------|---------|
| 逍遥 | 无待（无依赖）的自由状态 |
| 齐物 | 消解是非、彼此、大小等二元对立的视角 |
| 心斋 | 「唯道集虚。虚者，心斋也」（人间世）——清空成心的接收态 |
| 坐忘 | 「堕肢体，黜聪明，离形去知，同于大通」（大宗师）—— meditation 的先秦形态 |
| 无用之用 | 在主流价值标准之外的重定位 |
| 天理/固然 | 事物的自然纹理（庖丁解牛） |
| 悬解 | 「安时而处顺，哀乐不能入……帝之县解」（养生主）——解除倒悬 |

## 篇目主题速查（内篇）
- 逍遥游=自由的条件；齐物论=判断的相对性；养生主=顺势与有限性；人间世=乱世的自处（心斋）；德充符=内在充实vs外形；大宗师=生死与命；应帝王=无为的政治（「浑沌之死」警告强加秩序）
