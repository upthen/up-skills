# 庄子 · 决策记录与行动

> 生平资料有限（《史记·老子韩非列传》附传约200字），但《庄子》文本内的传记性材料（钓于濮水、贫而贷粟、妻死鼓盆、将死薄葬）有较高内证一致性。可信度逐条标注。

## 决策1：拒楚相（人生定义性决策）
- 「庄子钓于濮水，楚王使大夫二人往先焉，曰：『愿以境内累矣！』庄子持竿不顾」（秋水）
- 神龟之喻：宁曳尾于涂中，不留骨而贵
- 《史记》佐证：楚威王闻庄周贤，使使厚币迎之，许以为相。周笑谓使者：「子亟去，无污我……我宁游戏污渎之中自快，无为有国者所羁」
- 决策逻辑：相位=「留骨而贵」（死后被供奉的骨架）vs 活着在泥里摇尾巴——自由>权位的估值排序
→ 揭示：这不是清高姿态，是冷峻的期望值计算：权位的实际内容是被羁绊+被风险敞口
- 可信度：秋水寓言+史记传记双重源，较高

## 决策2：贫困中的不合作
- 「庄周家贫，故往贷粟于监河侯」（外物）——穷到借米，但仍拒绝体制路径
- 「处穷闾厄巷，困窘织屦，槁项黄馘者」（曹商讥语，列御寇）——住陋巷、打草鞋为生、脖子干枯面黄——曹商的讥讽反而提供了生活实况
- 《山木》：庄子衣大布而补之，正緳系履而过魏王。魏王曰：「何先生之惫邪？」庄子曰：「贫也，非惫也」——明确区分「贫」（资源少）与「惫」（道穷）：物质匮乏不等于精神失败
→ 揭示：对「贫/惫」的概念切割是其安身立命的关键决策——拒绝把经济状态内化为自我评价

## 决策3：妻死，鼓盆而歌（对丧失的处理）
- 「庄子妻死，惠子吊之，庄子则方箕踞鼓盆而歌」（至乐）
- 解释：人本无生，「杂乎芒芴之间，变而有气，气变而有形，形变而有生，今又变而之死，是相与为春秋冬夏四时行也」——死亡=季节轮转
- 「人且偃然寝于巨室，而我噭噭然随而哭之，自以为不通乎命」——哭是「不通」的表现
→ 揭示：不是无情，是把哀伤放在更大的时间尺度里处理——先哭（「我独何能无概然」——他承认最初也慨然）后歌
- 可信度：至乐篇外杂篇，但与养生主「安时处顺」内证一致

## 决策4：将死，反对厚葬（最后的立场声明）
- 「庄子将死，弟子欲厚葬之。庄子曰：吾以天地为棺椁，以日月为连璧，星辰为珠玑，万物为赍送。吾葬具岂不备邪？何以加此！」（列御寇）
- 弟子：怕乌鸢吃你。庄子：在上为乌鸢食，在下为蝼蚁食，夺彼与此，何其偏也！
→ 揭示：连自己尸体的处置都要打破「人为区别」——彻底到最后一刻；且论证方式仍是归谬（为什么偏心乌鸢欺负蝼蚁？）

## 决策5：与惠子的关系维护（友谊的决策）
- 惠子生前：从濠梁之辩到鹓鶵之讽——观点上毫不留情
- 惠子为相时猜忌庄子（搜于国中三日三夜），庄子主动往见，用故事化解
- 惠子死后：「自夫子之死也，吾无以为质矣」（徐无鬼）——过墓而叹，讲运斤成风
→ 揭示：对智性友谊的经营观——最好的关系是互为镜子与砥石；失去对手=失去自己一半

## 决策6：漆园吏的职业选择与退出
- 《史记》：周尝为蒙漆园吏——做过管漆树园的小吏（最底层公务员）
- 后辞职（时间不可考）——从体制边缘彻底退出到织屦为生
→ 揭示：不是从未入世，是入过、看过、算了账、退了——「人间世」篇对官场凶险的深刻分析（「伴君如伴虎」的「养虎」寓言）来自近距离观察

## 言行一致性检查

| 文本主张 | 行为记录 | 一致性 |
|------|------|--------|
| 拒权位 | 拒楚相（双源） | 一致——真拒绝过相位 |
| 安时处顺 | 妻死鼓盆（但「独何能无概然」——先有情绪再转化） | 一致且人性化 |
| 齐贵贱 | 「贫也非惫也」对魏王的自辩 | 一致——概念切割支撑了生活 |
| 无用之用 | 自处穷闾织屦——用「不材」保天年 | 一致 |
| 「相濡以沫不如相忘于江湖」 | 与惠子深度论辩不断、死后追念 | 微妙张力：主张相忘，实践上对「质」的关系极其珍视——他逃避的是体制羁绊，不是智性亲密 |
| 齐是非 | 文中对儒墨名家的批判锋利明确 | 核心张力：宣称无是非者的是非——荀子式批评的靶点，如实保留 |
