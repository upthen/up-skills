# 庄子 · 人物时间线

> 约前369-前286（学界通行估计，梁启超等考订范围略有出入）。宋国蒙人（今河南商丘东北/安徽蒙城有争议）。与梁惠王、齐宣王同时代，与惠施（约前370-前310）为友。历史人物，无时效性动态。

| 时间（约） | 事件 | 对思维的影响 |
|------------|------|------------|
| 前369 | 生于宋国蒙 | 宋为殷商后裔之国，文化边缘位置——主流体制外的视角起点 |
| 青年 | 为蒙漆园吏 | 体制最底层的任职经历——近距离观察权力运作 |
| 约前340s-330s | 与惠施相识论辩（惠子仕魏约前340s后） | 一生的智性对话者与镜子 |
| 中年 | 楚威王（在位前339-前329）遣使聘相，拒之 | 人生定义性决策：「宁曳尾于涂中」 |
| 约330s-310s | 惠施为魏相期间的冲突与和解（鹓鶵之讽） | 对权力场猜忌的亲历 |
| 约前310 | 惠施卒，过墓而叹「无以为质矣」 | 失去唯一对手的孤独 |
| 晚年 | 妻死鼓盆；将死命弟子薄葬，「以天地为棺椁」 | 生死的实践收官 |
| 约前286 | 卒（宋亡于同年前后——或亲见故国灭亡） | 其身后文本在秦汉际流传成书 |

## 文本形成史（学界主流）
1. 战国中期：内篇7篇约作于庄子手（Graham、刘笑敢等主流判断）
2. 战国晚期-秦汉：外杂篇由庄子后学及杨朱派等多家写成
3. 汉代：五十二篇本流传（刘向校定）
4. 西晋：郭象删定为33篇并作注——今本定型；「内圣外王」官方化
5. 唐代：尊称《南华真经》（道教升格，唐玄宗封庄子为南华真人）
6. 现代：马王堆、郭店出土文献带动老庄重估；内篇研究成为国际显学（Graham、Ziporyn等译本）

## 思想发展关键节点（从文本内证反推）
1. **漆园吏时期**：近距离看权力机器→「人间世」的养虎寓言（伴君如伴虎）的政治心理学
2. **拒相之后**：自由的具体化——不是口号，是「曳尾于涂中」的日常
3. **与惠子的多年论辩**：齐物论的论敌环境——「齐物」是在论辩中锻造的（为论辩辩护又消解论辩）
4. **惠子之死**：「无与言之矣」——智性孤独，晚年文本更内转（心斋、坐忘的深化）
5. **宋国将亡的背景**：乱世中的乱世——其「安命」不是太平岁月的哲学，是文明崩解期的生存策略

## 身后大事
- 郭象注（西晋）：体制收编，「游外冥内」调和仕与隐
- 唐代：道教升格为「南华真人」
- 宋明：士大夫「出处进退」的精神资源（仕途受挫时的心理庇护所）
- 近现代：鲁迅的文学史至高评价；闻一多「烙印」说（通行归因，原文未核验）；徐复观《中国艺术精神》确立其为中国美学源头
- 当代：松弛感、松弛美学的大众话语重新征用庄子——最新一轮「时代焦虑投影」
